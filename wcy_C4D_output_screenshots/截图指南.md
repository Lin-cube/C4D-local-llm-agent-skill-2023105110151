# 截图指南 —— 提交前必须补齐的截图

评审要求截图/录屏中**清晰显示**以下 4 项信息。建议在正式提交前，  
按《wcy_C4D_教学说明.md》重新跑一遍脚本并截图（Mac: `Cmd+Shift+4` 区域截图）：

## 必截 3 张

1. **模型与设备证明**  
   终端执行：
   ```bash
   ollama list && ollama ps && sysctl -n machdep.cpu.brand_string
   ```
   截图需包含：`gemma4:e4b  dc35e8d9c606  6.6 GB`、`100% GPU`、`Apple M4`
2. **模型运行中的推理速度**  
   运行 `python3 01_level1_chat.py`，截取包含  
   `速度 xx.xx tok/s` 和 `模型: gemma4:e4b` 的输出段落  
   （若想截"正在生成"的动态画面，可在终端 `ollama run gemma4:e4b` 聊天时录屏）
3. **交互式地图**  
   `open ../wcy_C4D_map.html` 后截图：需看到地图标题、彩色标记、  
   以及点击某个标记弹出的双语信息窗（左下角有 Leaflet 水印）

## 加分：30 秒录屏

录屏流程建议：终端跑脚本 → 浏览器打开地图 → 缩放/点击标记。  
Mac 录屏：`Cmd+Shift+5`。
